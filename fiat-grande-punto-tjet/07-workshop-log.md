# 07 — Workshop Log

Every visit gets an entry. No entry = it didn't happen (warranty claims and resale value depend on this file).

## Approved workshop criteria

- Has Fiat-capable diagnostics (MultiECUScan / Examiner / AlfaOBD) — mandatory for proxi, EPS, BSI work
- Torque wrench actually used (suspension + head work)
- Provides itemized invoice + warranty in writing
- Lets you keep replaced parts (proof of work done)
