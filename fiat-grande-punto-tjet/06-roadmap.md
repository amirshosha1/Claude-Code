# 06 — Project Roadmap

**Owner's 3-phase plan (July 2026) adopted:** Phase 1 سلامة واعتمادية = roadmap 0–3 · Phase 2 راحة = 4–5 · Phase 3 الشكل = 6–7.
Rule: a phase does not open until the previous phase's 🔴/🟠 items are closed.

## ⚡ Phase 1a — CONFIRMED FAILURES (this week, before anything else)
**Cost: EGP 4,000–10,000 + radiator verdict**
1. Expansion tank + cap → pressure test → radiator if confirmed → Paraflu UP/G12+ refill
2. Air-intake hose (filter→turbo) + clamp set — protects the original turbo TODAY
3. Accessory belt + tensioner + idler set (idle whistle)
Driving rules until done: distilled-water top-ups only · watch temp gauge · no hard pulls.

## Phase 0 — Baseline Diagnosis 🔴
**Cost:** EGP 1,500–3,500 · **Time:** 1–2 days · **Dependencies:** none
Full inspection per [`01-baseline-inspection.md`](01-baseline-inspection.md). Deliverable: measured facts replacing every "Unknown" in this project.

## Phase 1 — Safety 🔴 (revised — timing belt & front brakes already done per history)
**Cost:** EGP 8,000–40,000 (tires dominate) · **Time:** ~1 week · **Labor:** ~6–10 h · **Depends on:** Phase 0
- Brake fluid flush (never recorded) + caliper service + hose inspection
- Spark plugs (overdue at 43k km)
- Oil + all filters (no date on record)
- Tires if DOT-expired/worn; battery if CCA test fails
- Confirm-or-replace: coolant, gearbox oil
- Any Confirmed suspension failure from shake-down (front overhaul is 53k km old; rear shocks unrecorded)

## Phase 2 — Mechanical Reliability 🟠
**Cost:** EGP 20,000–45,000 · **Time:** 2–4 weeks · **Labor:** ~10–16 h · **Depends on:** Phase 1
- Oil service + all filters + plugs
- Gearbox oil; CV boots/joints as found
- PCV/cam cover if confirmed; coils as confirmed
- Cooling hoses/fans as found; grounds + scuttle drains
- Suspension rebuild (arms, links, struts, mounts) as found + final alignment

## Phase 3 — Performance 🟡
**Cost:** EGP 3,000–50,000 (evidence-dependent) · **Time:** 1–3 weeks · **Depends on:** Phase 2
- Boost system to spec: solenoid/hoses/actuator per diagnosis; turbo only on Confirmed failure
- Injector clean + throttle body clean; new air filter already in
- Exhaust leaks/flex pipe; verify full power run + boost log matches target
- 95 RON fuel discipline from Phase 0 onward

## Phase 4 — Comfort 🟡
**Cost:** EGP 3,000–15,000 · **Time:** 1 week · **Depends on:** Phase 3
- A/C system to full performance (leak-fix path)
- Blower/resistor, cabin sealing, door seals
- NVH: sound-deadening pass, remaining mount refresh

## Phase 5 — Interior 🟢
**Cost:** EGP 5,000–12,000 · **Time:** 1 week
Deep clean, upholstery repairs, steering wheel re-cover, trim restoration, interior LEDs.

## Phase 6 — Exterior 🟢
**Cost:** EGP 6,000–18,000 · **Time:** 1–2 weeks
Paint correction/per-panel respray, headlight restoration, glass chips, seals, badges.

## Phase 7 — Cosmetic Finale + Audio 🟢
**Cost:** EGP 8,000–25,000 · **Time:** 1 week
Head unit + speakers + camera, engine-bay detail, ceramic coat option, final photo documentation for the project file.
